# 🌐 WDF_SHP-BATCH_A

### Web Development Frameworks – Practical Work

A collection of practical assignments, source code, and exercises completed as part of the **Web Development Frameworks (WDF)** course.

This repository is organized to maintain practical implementations, explore web development concepts, and gain hands-on experience with modern web technologies.

---

## 📖 About the Repository

The purpose of this repository is to document and organize WDF laboratory practicals in one place.

It serves as a learning resource for understanding web development fundamentals, implementing framework-based applications, and practicing database-driven web development.

### 🎯 Objectives

- Understand modern web development concepts.
- Learn server-side web application development.
- Practice frontend and backend integration.
- Understand database connectivity and CRUD operations.
- Develop practical problem-solving skills.
- Maintain organized laboratory assignments.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/arabiyaniuzair/WDF_SHP-BATCH_A.git
```

### 2. Navigate to the Repository

```bash
cd WDF_SHP-BATCH_A
```

### 3. Open the Project

Open the repository in Visual Studio Code:

```bash
code .
```

### 4. Run the Practical

For HTML, CSS, and JavaScript projects, open the HTML file using Live Server or your browser.

For PHP projects, configure your local PHP environment and run the relevant project.

For Laravel projects:

```bash
composer install
```

Configure the `.env` file and database credentials, then run:

```bash
php artisan serve
```

**Note:** Follow the individual practical instructions where additional setup is required.
